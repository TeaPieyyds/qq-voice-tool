# 电脑版使用说明

把任意音频变成手机 QQ 里能直接播放的语音消息，**保留原录音的文件名**，一步替换。
不用再手动「录音取消 → 翻文件夹找名字 → 转 slk → 拷贝覆盖」。

---

## 一、怎么用

**日常启动只有一步：双击 `启动.bat`** —— 浏览器会自动打开 `http://127.0.0.1:8791`，不需要手输端口。

- 那个**黑色命令行窗口要留着别关**，关了就等于停止服务（关掉浏览器页面不影响）
- 重复双击也不会冲突：检测到已在运行就直接开页面
- 找不到窗口时，双击 `停止.bat` 可以强停
- 想更快启动：右键 `启动.bat` → 发送到 → 桌面快捷方式

然后：

1. 数据线连手机，手机上选「传输文件」并解锁（ADB 已配置好，平时插上就能用）
2. 拖入音频（wav/mp3/flac/ogg…），或直接粘贴文件路径回车
3. 列表里自动选中最新那条录音 → 点「替换并保持文件名」
4. 回手机 QQ，点那条语音试听

> **录音只是拿一个能发的「坑位」**：气泡上的秒数只是显示值，音频会被完整播放，录 1 秒也能塞 8 秒。
> QQ 只允许发送**最新录的那一条**，所以流程永远是：录一条 → 取消 → 工具自动选中它 → 替换 → 发送。
> 唯一真正的长度限制是 QQ 单条语音 60 秒上限，超过工具会提示。

## 二、为什么这么设计

### 1. 为什么格式转换用 SILK 而不是直接改名
手机 QQ 的语音文件是「`0x02` + `#!SILK_V3` + 若干 20ms 帧」的容器。
经实测，**手机端解码器严格要求开头那个 `0x02`**，
缺了就直接报错；PC 端容错，会跳过它继续解 —— 这就是当年「电脑能播、手机不能播」的根因。

工具内部流程：

```
任意音频 → 解码成 PCM → 下混单声道 → 重采样到 24kHz → 峰值保护
        → SILK 编码（自带 0x02、不带 FF FF）→ 结构校验
```

编码完会立刻做一次「解码回环」，时长对得上才算通过。

### 2. 为什么替换必须走 ADB，而不是 U 盘（MTP）模式
| 操作 | MTP（U 盘模式） | ADB |
|---|---|---|
| 读取 ptt 目录、列文件 | ✅ 可用 | ✅ 可用 |
| 写入**新**文件 | ✅ 可用 | ✅ 可用 |
| **覆盖**同名文件 | ❌ Android MTP 协议不支持 | ✅ 直接 push 覆盖 |
| 删除文件 | ❌ 需要交互确认，脚本调不动 | ✅ |

实际测试：MTP 覆盖会静默失败（原文件大小不变），删除动词在非交互进程里根本不执行。
所以设计成 **MTP 负责「看」，ADB 负责「写」**：
没开 ADB 时照样能扫描列表、能生成成品，只是替换按钮会提示你去开 USB 调试。

### 3. 为什么扫描要「跨日期自动找」
QQ 的缓存路径带日期：`ptt/YYYYMM/DD/`。工具不写死今天，
而是从 `ptt` 往下按月份、日期倒序找**第一个含 slk 的目录**，
所以跨零点、隔天再用都不会失效。

### 4. 为什么文件名要沿用原录音
QQ 的聊天记录里存的是这个文件名，只有名字对得上，点开才能播到你的音频。

## 三、目录结构

```
QQ语音工具/
├─ 启动.bat            双击运行（浏览器自动打开）
├─ 停止.bat            关不掉窗口时用它强制停止
├─ server.js           本地服务（127.0.0.1:8791，不对外）
├─ public/index.html   界面
├─ lib/
│  ├─ slkbuild.js      音频 → slk（解码/重采样/编码/校验）
│  ├─ adb.js           ADB 后端（扫描、拉取、推送、md5 校验）
│  ├─ mtp.js           MTP 后端（只读扫描、导出时长）
│  ├─ mtp.ps1          MTP 的 PowerShell 实现
│  └─ adbinstall.js    一键下载 platform-tools
├─ platform-tools/     自动装好的 adb
├─ 备份/               每次替换前的原文件（按时间戳分目录）
├─ 导出/               生成过的成品 slk（也用于「手动替换」）
└─ config.json         手机名称、QQ 号、备份开关
```

## 四、常见问题

**Q：列表里只有几条带时长，其他是「未解析」？**
时长需要把文件拉回本地才能算。工具只对最近 6 条做解析（MTP 每条约 1~2 秒），
其余按文件名里的时间排序显示，选中后一样能替换。

**Q：替换完了，手机 QQ 还是旧声音？**
QQ 会缓存已解码的音频。退出聊天窗口重进；仍不行就杀掉 QQ 重开。

**Q：气泡显示 1 秒，但音频有 8 秒？**
正常的，秒数只是显示值，点开能听完。不用为了对齐时长去录长语音。

**Q：列表里该选哪一条？**
工具默认就选中**最新**那条（带绿色「最新」标签）。因为 QQ 只能发送最新录的语音，
所以先录一条并取消，再来点「重新扫描」或直接替换即可。

**Q：能不能不插线？**
不行，需要改手机本地文件。无线 ADB 可以，但每次要重新配对，插线性价比更高。

**Q：会改坏我的语音吗？**
每次替换前原文件都会复制到 `备份/<时间戳>/`，出问题直接拷贝回去。

## 五、注意

这是替换本地缓存文件，属非官方用法，QQ 更新后路径或格式可能变化。
仅限自用娱乐，不要用于伪造他人语音等用途。
