# QQ 语音发送助手

把任意音频变成 QQ 里能直接播放的语音消息 —— 保留原录音的文件名，一键替换。
有**电脑版**和**手机版**，功能一样，按场景选一个。

---

> **语音素材**：另附一份[语音素材包](https://github.com/TheColt66/qq-voice-tool/releases/tag/assets-v1)（2502 个音频片段，约 299 MB）。
> 不想自己找音频的话，解压后随便挑一个，在工具里选中替换即可。

## 一句话流程

```
QQ 里按住说话滑到转文字（先别发送卡住这个录音）→ 打开本工具 → 选音频 → 点替换 → 回 QQ 试听 → 满意再发送
```

## 电脑版 · 怎么用

### 第一次使用

1. 装 [Node.js](https://nodejs.org/) 18 以上（一路下一步即可）
2. 手机开 USB 调试：设置 → 关于手机 → **连点「版本号」7 次** → 返回 → 开发者选项 → 打开 **USB 调试**
3. 数据线连电脑，手机上弹出「允许 USB 调试吗」→ 勾选**一律允许** → 确定
4. 双击 **`启动.bat`**（首次会自动装依赖，稍等一会儿）
   - 浏览器会自动打开 `http://127.0.0.1:8791`，**不用自己输地址**
   - 那个黑色命令行窗口**留着别关**，关掉就等于停止服务

### 每次使用

1. **在 QQ 里按住说话**，说完把手指滑到「**转文字**」再松手
   - 这一步的目的只是让 QQ 生成一条语音缓存，**先不要真的发出去**
2. 打开工具页面，拖入音频（wav / mp3 / flac / ogg / m4a 都行）
   - 也可以点下面的路径框，粘贴文件完整路径后回车
3. 等两三秒，出现参数卡片和试听播放器
4. 下面列表里**已经自动选中最新那条录音**（带绿色「最新」标签），必须选用最新的文件
5. 点底部 **「替换并保持文件名」**
6. 看到绿色的「已备份 / 已生成 / 已推送 / 校验通过」就成功了
7. **回 QQ，点输入框上方那条语音试听** —— 确认是你想要的声音

## 手机版 · 怎么用

### 第一次使用

1. 下载 Release 里的 `app-signed.apk` 安装（允许「安装未知来源应用」）
2. 装 [Shizuku](https://github.com/RikkaApps/Shizuku/releases) 并启动它的服务：
   - 手机连 **Wi-Fi**
   - 设置 → 开发者选项 → 打开 **无线调试**
   - 点「使用配对码配对设备」，记下 6 位数字
   - 打开 Shizuku →「配对」→ 输入数字 → 回主界面点「**启动**」
3. 打开「QQ 语音助手」→ 点「**授权**」→ 手机上点「**允许**」

> 用数据线启动 Shizuku 也行，但**一拔线服务就没了**（部分机型如此）。要拔线用，请走上面的无线调试。

### 每次使用

1. **在 QQ 里按住说话**，说完滑到「**转文字**」松手 —— 先别发出去
2. 打开 App，点「从文件里选一个音频」，选好等它转完（出现参数和试听）
3. 列表里**已自动选中最新那条**（绿色「最新」标签）
4. 点底部 **「替换并发送」**
5. **回 QQ 点那条语音试听**，满意再点发送
6. 原文件会自动备份到 `Download/QQ语音备份/<时间戳>/`

## 注意事项

**关于录音**

- 录音只是拿一个"能发送的位置"，**气泡上的秒数只是显示值**，音频会完整播放 —— 录 1 秒也能塞 30 秒，不需要为对齐时长去录长语音
- 唯一真正的限制是 **QQ 单条语音 60 秒上限**，超过可能被截断，工具会提示
- QQ 只能发送**最新录的那一条**，所以顺序不能反：先录，再替换

**关于手机版**

- 手机**重启后** Shizuku 服务会停，要重新走一次「连 Wi-Fi → 开无线调试 → Shizuku 点启动」
- 「配对」只需一次，之后都是打开开关点一下启动
- 授权是持久的，不用每次点「允许」
- 状态显示「未运行」→ 打开 Shizuku 点「启动」；点右上角徽章可以手动重查

**关于电脑版**

- 黑色窗口关掉 = 停止服务；窗口丢了双击 `停止.bat`
- 提示「找不到目录」时，通常是手机没解锁，或数据线插上后没选「传输文件」

**关于兼容性**

多 QQ 账号、应用分身、QQ 国际版/极速版、跨天（`202610/19` → `202610/20`）都已自动处理。
如果你的机型路径特殊，手机版「设置」里可以手动填 QQ 号和目录，留空则回到自动查找。

## 自己构建

电脑版：

```bash
npm install
node server.js        # 或双击 启动.bat
```

手机版（不依赖 Gradle，约 10 秒出包）：

```bash
# 需要 Android SDK（platforms;android-34 + build-tools;34.0.0）和 JDK 17
cd android
bash fetch-libs.sh                              # 拉 Shizuku 依赖
ANDROID_HOME=/path/to/Android/Sdk bash build.sh # 产物 out/app-signed.apk
adb install -r out/app-signed.apk
```
